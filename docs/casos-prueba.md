# Casos de prueba

| Código | Funcionalidad | Resultado esperado |
|---|---|---|
| CP-01 | Registrar cliente | El cliente se guarda con sus datos básicos. |
| CP-02 | Modificar cliente | La información seleccionada del cliente se actualiza. |
| CP-03 | Registrar servicio | El servicio registra nombre, precio y duración. |
| CP-04 | Registrar reserva | La reserva guarda cliente, servicio, fecha y hora. |
| CP-05 | Cancelar reserva | La reserva cambia a estado Cancelada. |
