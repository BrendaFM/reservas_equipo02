# Sistema de reservas - equipo 02

## ¿En qué consiste el proyecto?

Este proyecto simula un sistema de reservas para una empresa de servicios. Permitirá organizar clientes, servicios y reservas, reemplazando el uso de llamadas telefónicas, WhatsApp y hojas de cálculo.
